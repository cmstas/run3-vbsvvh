# Xbb tagger scale factors, Run 2 and Run 3

Scale factors (SF) of the GloParT Xbb tagger (XbbVsQCD discriminant) for jets with
m_SD in [40, 250] GeV, measured with the mu-tagged method, for all data-taking periods of
Run 2 (2016 PreVFP/PostVFP, 2017, 2018) and Run 3 (2022 preEE/postEE, 2023 preBPix/postBPix, 2024, 2025).

- Working points for scale factor derivation: 0.5, 0.6, 0.7, 0.8, 0.9, 0.99.
- Up / down variations: `SF + sigma_tot` and `SF - sigma_tot`, as measured with the mu-tagged method.
- pT bins (GeV, AK8 jet pT):
  - Run 2: [250, 300], [300, 400], [400, 450], [450, inf]
  - 2022 to 2025: [250, 300], [300, 350], [350, 425], [425, inf]

## correctionlib files

Files are named `Xbb_SF_<era>.json` (example `Xbb_SF_2022_preEE.json`).

### How to evaluate scale factor and variation

Example python code

```python
import numpy as np
import correctionlib

cset = correctionlib.CorrectionSet.from_file("Xbb_SF_2017.json")
corr = cset["Xbb_SF"]

corr.evaluate(0.7, 350.0, "nom")                         
corr.evaluate(0.7, 350.0, "up")                          
corr.evaluate(0.7, 350.0, "down")                        
corr.evaluate(0.7, np.array([260., 350., 500.]), "nom")  
```

- Inputs are `WP`, `pt` (GeV) and `systematic` (`nom`, `up`, `down`). `WP` and `pt` must be floats,
integers are rejected.
- Structure: binning on WP, then binning on pT, then the `systematic` category, then a formula
  `[0]+[1]*x` with `x = WP`: the straight line between the SF or up/down variation at the two neighbouring measured WPs.
- A WP outside [0.5, 0.99] raises an error.
- pT outside the bins is clamped: below 250 GeV the first bin is used, above the last bin edge
  (13000 GeV) the last bin is used. The last pT bin is open-ended, so large pT uses its values.
